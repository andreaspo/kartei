#### C. JavaScript Logik (am Ende des `<script>` Blocks)
Füge diese Funktion hinzu, um die Antwort von Google zu verarbeiten:

```javascript
function handleCredentialResponse(response) {
  // Das 'credential' ist ein JWT (JSON Web Token)
  if (response.credential) {
    // In einer reinen Client-Lösung blenden wir einfach den Content ein.
    // Für echte Sicherheit müsste das Token an ein PHP-Skript gesendet werden.
    
    document.getElementById("login-overlay").style.display = "none";
    document.getElementById("main-content").style.display = "block";
    
    // Optional: User-Daten aus dem Token extrahieren (ohne Passwort, nur Name/Mail)
    const payload = JSON.parse(atob(response.credential.split('.')[1]));
    console.log("Willkommen, " + payload.name);
  }
}
